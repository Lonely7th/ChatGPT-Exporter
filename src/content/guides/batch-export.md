ChatGPT Exporter 的批量导出用于在**当前对话中选择多条消息**，再合并为 Word 或 Markdown 文件。它适合保存连续讨论、完整推导或专题问答。

这项功能不等同于一键备份账号里的所有历史会话。

## 批量导出的操作步骤

1. 打开要整理的对话，先加载需要保留的消息。
2. 找到并点击“批量导出”入口。
3. 勾选当前对话中需要合并的消息，检查选择范围。
4. 选择“导出 Word”或“导出 MD”。
5. 按提示完成必要的登录，等待转换和下载。
6. 打开文件，检查消息顺序、内容完整性和标题。

界面布局可能随 ChatGPT 和插件版本变化，以当前可见入口为准。未加载、未选中的消息不能被假定已经包含在文件中。

## Word 与 Markdown 怎么选？

| 格式     | 更适合的任务               | 使用前提                       |
| -------- | -------------------------- | ------------------------------ |
| Word     | 编辑报告、打印、向他人交付 | 用目标文档软件检查版式         |
| Markdown | 保存文本结构、继续编辑源码 | 由目标编辑器解释公式和图表语法 |

Markdown 文件中的 LaTeX 或图表代码能否直接显示，取决于打开它的编辑器是否支持相应语法。

## 如何整理较长的对话？

先按主题分段导出，分别检查结果，再决定是否合并。这样也更容易在转换失败时定位问题。

建议优先保留与你的目标直接相关的提问和回答，减少无关追问。导出后可以补充主题、日期与必要背景，方便日后检索。

## 如果想备份整个账号怎么办？

账号级数据导出和当前对话整理是不同任务。需要全部历史数据时，请查看 ChatGPT 产品内当前可用的数据导出选项和说明。本网站不将插件的批量选择能力宣传为账号级完整备份。

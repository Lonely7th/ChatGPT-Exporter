导出异常时，先确定问题发生在哪一步：看不到按钮、无法开始转换、生成文件失败，还是下载后的排版不符合预期。按顺序排查，通常比重复点击导出更有效。

## 一、看不到导出入口

1. 确认访问的是 `chatgpt.com` 的对话页面。
2. 打开浏览器扩展管理页面，确认插件已经启用。
3. 检查插件是否获得当前站点的访问权限。
4. 刷新页面，等待回答和界面加载完成。
5. 如仍异常，检查是否安装了影响同一区域的其他扩展，并记录版本与现象。

如果插件刚安装完成，已经打开的 ChatGPT 页面可能需要刷新后才能显示入口。

## 二、点击后无法完成转换

- 查看是否出现登录、额度或会员权益提示，按实际提示处理。
- 确认网络能够连接转换服务，避免中途关闭页面。
- 先测试一段较短、没有复杂嵌套的内容。
- 等待本次处理结束后再重试，避免重复提交相同任务。

联网、登录和转换是不同环节；能够打开官网不代表所有转换请求都能成功。

## 三、内容缺失或顺序不符

检查原始回答是否已生成完成，以及批量模式中需要的消息是否已加载并选中。重新选取较小范围，对比导出内容，再逐步扩大选择范围。

对于超长对话，按主题分段导出，检查每段结果后再整理。

## 四、公式、表格或代码排版异常

| 现象                     | 建议动作                           |
| ------------------------ | ---------------------------------- |
| 公式显示为源码           | 核对源表达，单独导出该公式进行测试 |
| 公式看起来正常但不能编辑 | 确认对象类型，区分显示正确与可编辑 |
| 表格超出页面             | 在 Word 中调整列宽、纸张方向或分页 |
| 代码长行截断             | 调整页面、字号或换行设置           |
| 字体不同                 | 检查目标设备的字体可用性           |

在 Word 与 WPS 中分别打开的结果可能不同，应以实际交付环境验收。需要固定版式分享时，可在调整好文档后生成 PDF。

## 五、如何提交有效反馈？

请提供：浏览器版本、插件版本、操作系统、导出格式、错误提示、复现步骤，以及脱敏后的最小内容样例。涉及文件排版时，补充文档软件名称和版本。

不要发送账号口令、登录令牌或未脱敏的敏感对话。[查看联系方式](/about/)。
